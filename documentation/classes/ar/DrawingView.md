# DrawingView

## معلومات عامة
مكون واجهة مستخدم مخصص يعمل كلوحة رسم. يمكن للمستخدمين رسم خطوط (روابط) ووضع رموز كيميائية عليها.

## جدول المتغيرات
| الاسم | النوع | الوصف |
|---|---|---|
| drawPaint | Paint | إعدادات رسم الخطوط. |
| textPaint | Paint | إعدادات رسم رموز العناصر. |
| drawPath | Path | المسار الحالي الذي يتم رسمه. |
| elementTexts | List<ElementText> | قائمة الرموز الموضوعة على لوحة الرسم. |
| currentSelectedElement | String | الرمز الذي سيتم وضعه تالياً. |

## تفاصيل الأساليب
| الاسم | المعلمات | الإرجاع | المنطق |
|---|---|---|---|
| onDraw | Canvas | void | يرسم الصورة النقطية للخلفية، والمسار الحالي، وجميع الرموز الموضوعة. |
| onTouchEvent | MotionEvent | boolean | يتعامل مع حركة الإصبع لرسم الخطوط أو النقر لوضع العناصر. |
| clearCanvas | لا يوجد | void | يعيد ضبط الرسم. |
| getBitmap | لا يوجد | Bitmap | يلتقط لوحة الرسم بالكامل كصورة لتحليل الذكاء الاصطناعي. |

## دورة الحياة
- N/A (جزء من واجهة مستخدم النشاط).

## واجهة المستخدم
- يستخدم في `activity_drawing.xml`.

## التفاعل بين المكونات
- يتفاعل مع `DrawingActivity` لاستقبال العناصر المختارة.

## المنطق العام
إذا تم اختيار عنصر من اللوحة، فإن النقرة التالية تضع هذا الرمز. إذا لم يتم اختيار عنصر، فإن حركة الإصبع ترسم خطوطاً مثل القلم.

## شرح مبسط
سبورة رقمية حيث يمكنك رسم الروابط الكيميائية بإصبعك والنقر لوضع الذرات في مكانها.
