# Element

## معلومات عامة
فئة "نموذج" تمثل عنصراً كيميائياً واحداً من الجدول الدوري.

## جدول المتغيرات
| الاسم | النوع | الوصف |
|---|---|---|
| id | int | معرف قاعدة البيانات. |
| symbol | String | الرمز الكيميائي (مثل "H", "O"). |
| name | String | الاسم الكامل (مثل "الهيدروجين"). |
| atomicNumber | int | الموقع في الجدول الدوري. |
| atomicMass | double | الكتلة الذرية. |

## تفاصيل الأساليب
- أساليب Getter و Setter لجميع المتغيرات.

## دورة الحياة
- N/A (كائن جافا قياسي).

## واجهة المستخدم
- N/A (نموذج بيانات).

## التفاعل بين المكونات
- يمرر بين الأنشطة ويستخدم بواسطة المحولات لعرض معلومات العنصر.

## المنطق العام
حاوية بسيطة للبيانات.

## شرح مبسط
مخطط لذرة. يتتبع اسمها ورمزها ورقمها في الجدول الدوري.
