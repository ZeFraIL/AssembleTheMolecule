# FormulaUtils

## معلومات عامة
فئة أدوات لمعالجة وتنسيق الصيغ الكيميائية.

## جدول المتغيرات
| الاسم | النوع | الوصف |
|---|---|---|
| N/A | N/A | لا توجد حالة محفوظة. |

## تفاصيل الأساليب
| الاسم | المعلمات | الإرجاع | المنطق |
|---|---|---|---|
| normalize | String formula | String | يزيل المؤشرات '1' (مثال: "H2O1" -> "H2O"). |
| formatForDisplay | String formula | String | يحول الأرقام إلى رموز سفلية بترميز UTF-8 (مثال: "H2O" -> "H₂O"). |
| getSubscript | char c | char | يربط الرقم بحرف الرمز السفلي المقابل له. |

## دورة الحياة
- N/A (أساليب أدوات ثابتة).

## واجهة المستخدم
- N/A (مساعد لمكونات واجهة المستخدم).

## التفاعل بين المكونات
- يستخدم بواسطة `GameActivity` و `SubstanceAdapter` و `MoleculeModelActivity`.

## المنطق العام
يستخدم التعبيرات العادية ومعالجة السلاسل النصية لضمان ظهور الصيغ بشكل "علمي" على الشاشة وسهولة مقارنتها في الكود.

## شرح مبسط
مساعد يعرف كيفية كتابة الصيغ الكيميائية بشكل صحيح، مثل جعل الأرقام صغيرة وفي الأسفل (الرموز السفلية).
