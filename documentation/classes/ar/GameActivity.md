# GameActivity

## معلومات عامة
نشاط اللعب الأساسي حيث يقوم المستخدمون بتجميع الصيغ الكيميائية. يدعم وضعين: "لعبة" (تجميع مادة معينة) و"مختبر" (تجربة العناصر لمعرفة ما تشكله).

## جدول المتغيرات
| الاسم | النوع | الوصف |
|---|---|---|
| tvTask | TextView | يعرض الهدف الحالي. |
| tvSubstanceName | TextView | يعرض اسم المادة المستهدفة أو التي تم العثور عليها. |
| tvFormulaDisplay | TextView | يعرض الصيغة أثناء بنائها. |
| rvElements | RecyclerView | قائمة قابلة للتمرير للعناصر الكيميائية. |
| helperDB | HelperDB | مساعد قاعدة البيانات لتحميل العناصر والمواد. |
| currentFormulaAtoms | List<SelectedAtom> | يخزن الذرات التي أضافها المستخدم. |
| mode | String | "game" أو "lab". |
| targetSubstance | Substance | المادة التي يحتاج المستخدم لتجميعها في وضع اللعبة. |

## تفاصيل الأساليب
| الاسم | المعلمات | الإرجاع | المنطق |
|---|---|---|---|
| initViews | لا يوجد | void | يجد مكونات واجهة المستخدم ويقوم بإعداد مستمعي النقر لأزرار العمل. |
| loadElements | لا يوجد | void | يجلب جميع العناصر من قاعدة البيانات ويعرضها في RecyclerView. |
| setupGame | لا يوجد | void | يضبط واجهة المستخدم بناءً على ما إذا كان الوضع "game" أو "lab". |
| changeIndex | int delta | void | يزيد أو ينقص الفهرس السفلي لآخر ذرة مضافة. |
| updateDisplay | لا يوجد | void | يحدث عرض الصيغة مع الرموز السفلية باستخدام `FormulaUtils`. |
| checkFormula | لا يوجد | void | يتحقق من الصيغة المجمعة مقابل الهدف (لعبة) أو يبحث عنها في قاعدة البيانات (مختبر). |

## دورة الحياة
- `onCreate`: يهيئ البيانات وواجهة المستخدم ويحمل العناصر.

## واجهة المستخدم
- `activity_game.xml`: يتميز بلوحة عناصر، أزرار عمل (فهرس+، فهرس-، مسح، تفريغ، تحقق)، وشاشات عرض للمهمة والصيغة.

## التفاعل بين المكونات
- يستخدم `HelperDB` للبيانات.
- يستخدم `ElementAdapter` لعرض العناصر.
- يستخدم `FormulaUtils` للتنسيق والتوحيد.

## المنطق العام
ينقر المستخدمون على العناصر من القائمة لإضافتها إلى الصيغة. يمكنهم ضبط المؤشرات (مثل H₂ بدلاً من H) واستخدام الأقواس. يحدد زر "تحقق" ما إذا كانت الصيغة تطابق الهدف أو موجودة في قاعدة البيانات.

## شرح مبسط
هنا يحدث السحر! يمكنك اختيار الذرات من قائمة لبناء الجزيئات. في وضع "اللعبة"، يعطيك التطبيق اسماً، وتحاول بناءه. في وضع "المختبر"، يمكنك خلط أي شيء ومعرفة ما إذا كانت مادة حقيقية!
