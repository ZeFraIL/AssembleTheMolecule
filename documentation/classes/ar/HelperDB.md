# HelperDB

## معلومات عامة
فئة مساعدة لقاعدة البيانات تدير قاعدة بيانات SQLite (`chemistry.db`). تتعامل مع إنشاء الجداول وتعبئة البيانات الأولية من ملفات JSON.

## جدول المتغيرات
| الاسم | النوع | الوصف |
|---|---|---|
| DATABASE_NAME | String | اسم الملف على القرص. |
| DATABASE_VERSION | int | يستخدم لإدارة تحديثات قاعدة البيانات. |

## تفاصيل الأساليب
| الاسم | المعلمات | الإرجاع | المنطق |
|---|---|---|---|
| onCreate | SQLiteDatabase db | void | ينشئ جداول `elements` و `substances` و `progress`. |
| seedData | SQLiteDatabase db | void | يستدعي الأساليب لتحميل البيانات الأولية من JSON. |
| seedElements | SQLiteDatabase db | void | يحلل `elements.json` من الأصول ويدرجها في الجدول. |
| seedSubstances | SQLiteDatabase db | void | يحلل `substances.json` من الأصول ويدرجها في الجدول. |
| loadJSONFromAsset| String fileName | String | يقرأ ملفاً من مجلد `assets` كسلسلة نصية. |

## دورة الحياة
- يديره نظام أندروאיד. يتم استدعاء `onCreate` عند الوصول إلى قاعدة البيانات لأول مرة.

## واجهة المستخدم
- N/A (إدارة البيانات فقط).

## التفاعل بين المكونات
- يستخدم بواسطة `GameActivity` و `SubstanceListActivity` و `DrawingActivity` لجلب البيانات الكيميائية.

## المنطق العام
يضمن أن التطبيق لديه جميع المعلومات الكيميائية (العناصر، الأسماء، الصيغ) جاهزة للاستخدام. إذا زاد إصدار قاعدة البيانات، يمكنه إعادة إنشاء الجداول لتحديث البيانات.

## شرح مبسط
تعمل هذه الفئة مثل أمين المكتبة. تقوم بإعداد الأرفف (الجداول) وتملأها بالكتب (البيانات الكيميائية) حتى يتمكن باقي التطبيق من العثور على ما يحتاجه.
