# Substance

## معلومات عامة
فئة "نموذج" تمثل مادة كيميائية (جزيء أو مركب).

## جدول المتغيرات
| الاسم | النوع | الوصف |
|---|---|---|
| id | int | معرف قاعدة البيانات. |
| formula | String | الصيغة الكيميائية (مثل "H2O"). |
| name | String | الاسم الشائع (مثل "الماء"). |
| className | String | الفئة الكيميائية (مثل "أكسيد"). |
| difficulty | int | مستوى الصعوبة للعب. |

## تفاصيل الأساليب
- أساليب Getter و Setter لجميع المتغيرات.

## دورة الحياة
- N/A (كائن جافا قياسي).

## واجهة المستخدم
- N/A (نموذج بيانات).

## التفاعل بين المكونات
- تستخدم على نطاق واسع في `GameActivity` و `SubstanceListActivity` و `DrawingActivity`.

## المنطق العام
تحتفظ بجميع التفاصيل حول مادة كيميائية معينة.

## شرح مبسط
مجلد يحتوي على كل ما نعرفه عن مادة معينة: اسمها وصيغتها والمجموعة التي تنتمي إليها.
