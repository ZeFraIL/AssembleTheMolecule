# DrawingView

## מידע כללי
רכיב ממשק משתמש מותאם אישית הפועל כקנבס. משתמשים יכולים לצייר קווים (קשרים) ולמקם עליו סמלים כימיים.

## טבלת משתנים
| שם | סוג | תיאור |
|---|---|---|
| drawPaint | Paint | הגדרות לציור קווים. |
| textPaint | Paint | הגדרות לציור סמלי יסודות. |
| drawPath | Path | הקו הנוכחי שמצויר. |
| elementTexts | List<ElementText> | רשימת סמלים שמוקמו על הקנבס. |
| currentSelectedElement | String | הסמל שימוקם בשלב הבא. |

## פירוט שיטות
| שם | פרמטרים | החזרה | לוגיקה |
|---|---|---|---|
| onDraw | Canvas | void | מצייר את מפת הסיביות של הרקע, את הנתיב הנוכחי ואת כל הסמלים שמוקמו. |
| onTouchEvent | MotionEvent | boolean | מטפל בתנועת אצבע לציור קווים או הקשה למיקום יסודות. |
| clearCanvas | ללא | void | מאפס את הציור. |
| getBitmap | ללא | Bitmap | לוכד את הקנבס כולו כתמונה לניתוח AI. |

## מחזור חיים
- N/A (חלק מממשק המשתמש של הפעילות).

## ממשק משתמש
- בשימוש ב-`activity_drawing.xml`.

## אינטראקציה בין רכיבים
- מקיים אינטראקציה עם `DrawingActivity` כדי לקבל יסודות נבחרים.

## לוגיקה כללית
אם נבחר יסוד מהפלטה, ההקשה הבאה ממקמת את הסמל הזה. אם לא נבחר יסוד, תנועת האצבע מציירת קווים כמו עט.

## הסבר פשוט
לוח מחיק דיגיטלי שבו אתם יכולים לצייר קשרים כימיים עם האצבע ולהקיש כדי לשים אטומים במקום.
