| שם | סוג | תיאור |
|---|---|---|
| id | int | מזהה במסד הנתונים. |
| symbol | String | סמל כימי (למשל, "H", "O"). |
| name | String | שם מלא (למשל, "מימן"). |
| atomicNumber | int | מיקום בטבלה המחזורית. |
| atomicMass | double | מסה אטומית. |
