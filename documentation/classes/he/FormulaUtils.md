# FormulaUtils

## מידע כללי
מחלקת עזר (utility) לעיבוד ועיצוב נוסחאות כימיות.

## טבלת משתנים
| שם | סוג | תיאור |
|---|---|---|
| N/A | N/A | לא נשמר מצב. |

## פירוט שיטות
| שם | פרמטרים | החזרה | לוגיקה |
|---|---|---|---|
| normalize | String formula | String | מסירה אינדקסים של '1' (למשל, "H2O1" -> "H2O"). |
| formatForDisplay | String formula | String | הופכת ספרות לאינדקסים תחתיים ב-UTF-8 (למשל, "H2O" -> "H₂O"). |
| getSubscript | char c | char | ממפה ספרה לתו האינדקס התחתי שלה. |

## מחזור חיים
- N/A (שיטות עזר סטטיות).

## ממשק משתמש
- N/A (עוזר לרכיבי ממשק משתמש).

## אינטראקציה בין רכיבים
- בשימוש על ידי `GameActivity`, `SubstanceAdapter` ו-`MoleculeModelActivity`.

## לוגיקה כללית
משתמשת בביטויים רגולריים ומניפולציות על מחרוזות כדי להבטיח שהנוסחאות ייראו "מדעיות" על המסך ויהיו קלות להשוואה בקוד.

## הסבר פשוט
עוזר שיודע לכתוב נוסחאות כימיות בצורה נכונה, כמו להפוך את המספרים לקטנים ובתחתית (אינדקסים תחתיים).
