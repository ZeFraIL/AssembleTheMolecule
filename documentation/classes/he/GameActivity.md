# GameActivity

## מידע כללי
פעילות המשחק המרכזית שבה המשתמשים מרכיבים נוסחאות כימיות. היא תומכת בשני מצבים: "משחק" (הרכבת חומר ספציפי) ו"מעבדה" (ניסוי באלמנטים כדי לראות מה הם יוצרים).

## טבלת משתנים
| שם | סוג | תיאור |
|---|---|---|
| tvTask | TextView | מציג את המטרה הנוכחית. |
| tvSubstanceName | TextView | מציג את שם החומר המיועד או שנמצא. |
| tvFormulaDisplay | TextView | מציג את הנוסחה תוך כדי בנייה. |
| rvElements | RecyclerView | רשימה נגללת של יסודות כימיים. |
| helperDB | HelperDB | עוזר מסד נתונים לטעינת יסודות וחומרים. |
| currentFormulaAtoms | List<SelectedAtom> | מאחסן את האטומים שנוספו על ידי המשתמש. |
| mode | String | "game" או "lab". |
| targetSubstance | Substance | החומר שהמשתמש צריך להרכיב במצב משחק. |

## פירוט שיטות
| שם | פרמטרים | החזרה | לוגיקה |
|---|---|---|---|
| initViews | ללא | void | מוצאת רכיבי ממשק משתמש ומגדירה מאזיני לחיצה לכפתורי פעולה. |
| loadElements | ללא | void | שולפת את כל היסודות ממסד הנתונים ומציגה אותם ב-RecyclerView. |
| setupGame | ללא | void | מגדירה את ממשק המשתמש בהתאם למצב "משחק" או "מעבדה". |
| changeIndex | int delta | void | מגדילה או מקטינה את האינדקס התחתי של האטום האחרון שנוסף. |
| updateDisplay | ללא | void | מעדכנת את תצוגת הנוסחה עם אינדקסים תחתיים באמצעות `FormulaUtils`. |
| checkFormula | ללא | void | בודקת את הנוסחה שהורכבה מול היעד (משחק) או מחפשת אותה במסד הנתונים (מעבדה). |

## מחזור חיים
- `onCreate`: מאתחלת נתונים, ממשק משתמש וטוענת יסודות.

## ממשק משתמש
- `activity_game.xml`: כולל פלטת יסודות, כפתורי פעולה (אינדקס+, אינדקס-, מחק, נקה, בדוק), ותצוגות למשימה ולנוסחה.

## אינטראקציה בין רכיבים
- משתמשת ב-`HelperDB` לנתונים.
- משתמשת ב-`ElementAdapter` להצגת יסודות.
- משתמשת ב-`FormulaUtils` לעיצוב ונרמול.

## לוגיקה כללית
משתמשים מקישים על יסודות מהרשימה כדי להוסיף אותם לנוסחה. הם יכולים להתאים אינדקסים (למשל, H₂ במקום H) ולהשתמש בסוגריים. כפתור "בדוק" קובע אם הנוסחה תואמת ליעד או קיימת במסד הנתונים.

## הסבר פשוט
כאן קורה הקסם! אתם יכולים לבחור אטומים מרשימה כדי לבנות מולקולות. במצב 'משחק', האפליקציה נותנת לכם שם, ואתם מנסים לבנות אותו. במצב 'מעבדה', אתם יכולים לערבב כל דבר ולראות אם זה חומר אמיתי!
