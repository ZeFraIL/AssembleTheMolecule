# HelperDB

## מידע כללי
מחלקה לעזרה במסד נתונים המנהלת את מסד הנתונים SQLite (`chemistry.db`). היא מטפלת ביצירת טבלאות ומאכלסת נתונים ראשוניים מקובצי JSON.

## טבלת משתנים
| שם | סוג | תיאור |
|---|---|---|
| DATABASE_NAME | String | שם הקובץ בדיסק. |
| DATABASE_VERSION | int | משמש לניהול עדכוני מסד נתונים. |

## פירוט שיטות
| שם | פרמטרים | החזרה | לוגיקה |
|---|---|---|---|
| onCreate | SQLiteDatabase db | void | יוצרת את הטבלאות `elements`, `substances` ו-`progress`. |
| seedData | SQLiteDatabase db | void | קוראת לשיטות לטעינת נתונים ראשוניים מ-JSON. |
| seedElements | SQLiteDatabase db | void | מנתחת את `elements.json` מהנכסים ומכניסה לטבלה. |
| seedSubstances | SQLiteDatabase db | void | מנתחת את `substances.json` מהנכסים ומכניסה לטבלה. |
| loadJSONFromAsset| String fileName | String | קוראת קובץ מתיקיית ה-`assets` כמחרוזת. |

## מחזור חיים
- מנוהל על ידי מערכת אנדרואיד. `onCreate` נקראת כאשר ניגשים למסד הנתונים בפעם הראשונה.

## ממשק משתמש
- N/A (ניהול נתונים בלבד).

## אינטראקציה בין רכיבים
- בשימוש על ידי `GameActivity`, `SubstanceListActivity` ו-`DrawingActivity` לשליפת נתונים כימיים.

## לוגיקה כללית
היא מבטיחה שלאפליקציה יש את כל המידע הכימי (יסודות, שמות, נוסחאות) מוכן לשימוש. אם גרסת מסד הנתונים עולה, היא יכולה ליצור מחדש את הטבלאות כדי לעדכן את הנתונים.

## הסבר פשוט
מחלקה זו פועלת כמו ספרנית. היא מקימה את המדפים (טבלאות) וממלאת אותם בספרים (נתונים כימיים) כדי ששאר האפליקציה תוכל למצוא את מה שהיא צריכה.
