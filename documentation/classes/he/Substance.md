# Substance

## מידע כללי
מחלקה מסוג "Model" המייצגת חומר כימי (מולקולה או תרכובת).

## טבלת משתנים
| שם | סוג | תיאור |
|---|---|---|
| id | int | מזהה במסד הנתונים. |
| formula | String | נוסחה כימית (למשל, "H2O"). |
| name | String | שם נפוץ (למשל, "מים"). |
| className | String | מחלקה כימית (למשל, "תחמוצת"). |
| difficulty | int | רמת קושי עבור המשחק. |

## פירוט שיטות
- שיטות Getter ו-Setter עבור כל המשתנים.

## מחזור חיים
- N/A (אובייקט Java סטנדרטי).

## ממשק משתמש
- N/A (מודל נתונים).

## אינטראקציה בין רכיבים
- בשימוש נרחב ב-`GameActivity`, `SubstanceListActivity` ו-`DrawingActivity`.

## לוגיקה כללית
מחזיקה את כל הפרטים על חומר כימי ספציפי.

## הסבר פשוט
תיקייה שמכילה את כל מה שאנחנו יודעים על חומר ספציפי: השם שלו, הנוסחה שלו, ולאיזו קבוצה הוא שייך.
