# DrawingActivity

## Общая информация
Активность, в которой пользователям предлагается нарисовать структуру конкретной молекулы. Она использует ИИ для проверки правильности рисунка.

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| drawingView | DrawingView | Интерактивный холст. |
| aiAssistant | AiAssistant | Обработчик Gemini AI. |
| rvElementPalette | RecyclerView | Список элементов для выбора при рисовании. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| setupPalette | Нет | void | Загружает элементы в горизонтальный прокручиваемый список. |
| analyzeWithAi | Нет | void | Делает скриншот рисунка и отправляет его ИИ. |

## Жизненный цикл
- `onCreate`: Настраивает холст и выбирает случайную молекулу для рисования.

## Пользовательский интерфейс
- `activity_drawing.xml`: Верхняя информационная панель, центральная область рисования, нижняя палитра элементов.

## Взаимодействие между компонентами
- Использует `AiAssistant` для проверки.
- Взаимодействует с `DrawingView` для размещения атомов.

## Общая логика
Приложение дает вам название вещества. Вы выбираете элементы и рисуете связи между ними. Когда закончите, вы нажимаете «Анализировать», и ИИ говорит вам, правильно ли вы это сделали.

## Упрощенное объяснение
Это творческий вызов! Вам нужно нарисовать, как атомы соединены в молекуле. Как только вы закончите свой эскиз, «учитель» в виде ИИ посмотрит на него и даст вам отзыв.
