# DrawingView

## Общая информация
Пользовательский компонент интерфейса, который служит холстом. Пользователи могут рисовать линии (связи) и размещать на нем химические символы.

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| drawPaint | Paint | Настройки для рисования линий. |
| textPaint | Paint | Настройки для рисования символов элементов. |
| drawPath | Path | Текущая рисуемая линия. |
| elementTexts | List<ElementText> | Список символов, размещенных на холсте. |
| currentSelectedElement | String | Символ, который будет размещен следующим. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| onDraw | Canvas | void | Рисует фоновое растровое изображение, текущий путь и все размещенные символы. |
| onTouchEvent | MotionEvent | boolean | Обрабатывает движение пальца для рисования линий или касание для размещения элементов. |
| clearCanvas | Нет | void | Сбрасывает рисунок. |
| getBitmap | Нет | Bitmap | Захватывает весь холст как изображение для анализа ИИ. |

## Жизненный цикл
- Н/Д (Часть пользовательского интерфейса активности).

## Пользовательский интерфейс
- Используется в `activity_drawing.xml`.

## Взаимодействие между компонентами
- Взаимодействует с `DrawingActivity` для получения выбранных элементов.

## Общая логика
Если элемент выбран из палитры, следующее касание размещает этот символ. Если элемент не выбран, движение пальца рисует линии, как ручка.

## Упрощенное объяснение
Цифровая доска, на которой вы можете рисовать химические связи пальцем и нажимать, чтобы ставить атомы на свои места.
