# Element

## Общая информация
Класс-модель, представляющий один химический элемент из периодической таблицы.

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| id | int | ID в базе данных. |
| symbol | String | Химический символ (например, "H", "O"). |
| name | String | Полное название (например, "Водород"). |
| atomicNumber | int | Порядковый номер в периодической таблице. |
| atomicMass | double | Атомная масса. |

## Детали методов
- Методы Геттеры и Сеттеры для всех переменных.

## Жизненный цикл
- Н/Д (Стандартный Java-объект).

## Пользовательский интерфейс
- Н/Д (Модель данных).

## Взаимодействие между компонентами
- Передается между активностями и используется адаптерами для отображения информации об элементах.

## Общая логика
Простой контейнер для данных.

## Упрощенное объяснение
Чертеж атома. Он хранит его название, символ и номер в периодической таблице.
