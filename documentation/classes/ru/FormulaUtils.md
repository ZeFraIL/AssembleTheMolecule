# FormulaUtils

## Общая информация
Утилитарный класс для обработки и форматирования химических формул.

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| N/A | N/A | Состояние не поддерживается. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| normalize | String formula | String | Удаляет индексы '1' (например, "H2O1" -> "H2O"). |
| formatForDisplay | String formula | String | Преобразует цифры в подстрочные знаки UTF-8 (например, "H2O" -> "H₂O"). |
| getSubscript | char c | char | Сопоставляет цифру с соответствующим подстрочным символом. |

## Жизненный цикл
- Н/Д (Статические утилитарные методы).

## Пользовательский интерфейс
- Н/Д (Помощник для компонентов интерфейса).

## Взаимодействие между компонентами
- Используется в `GameActivity`, `SubstanceAdapter` и `MoleculeModelActivity`.

## Общая логика
Использует регулярные выражения и манипуляции со строками, чтобы формулы выглядели «научно» на экране и их было легко сравнивать в коде.

## Упрощенное объяснение
Помощник, который знает, как правильно писать химические формулы, например, делая цифры маленькими и внизу (индексы).
