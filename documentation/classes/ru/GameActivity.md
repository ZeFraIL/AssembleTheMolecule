# GameActivity

## Общая информация
Основное игровое окно, где пользователи составляют химические формулы. Поддерживает два режима: «Игра» (собрать конкретное вещество) и «Лаборатория» (экспериментировать с элементами, чтобы увидеть, что они образуют).

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| tvTask | TextView | Отображает текущую задачу. |
| tvSubstanceName | TextView | Показывает название целевого или найденного вещества. |
| tvFormulaDisplay | TextView | Показывает формулу в процессе сборки. |
| rvElements | RecyclerView | Прокручиваемый список химических элементов. |
| helperDB | HelperDB | Помощник базы данных для загрузки элементов и веществ. |
| currentFormulaAtoms | List<SelectedAtom> | Хранит атомы, добавленные пользователем. |
| mode | String | "game" (игра) или "lab" (лаборатория). |
| targetSubstance | Substance | Вещество, которое пользователю нужно собрать в игровом режиме. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| initViews | Нет | void | Находит компоненты интерфейса и настраивает слушателей кликов для кнопок. |
| loadElements | Нет | void | Извлекает все элементы из БД и отображает их в RecyclerView. |
| setupGame | Нет | void | Настраивает интерфейс в зависимости от режима ("game" или "lab"). |
| changeIndex | int delta | void | Увеличивает или уменьшает подстрочный индекс последнего добавленного атома. |
| updateDisplay | Нет | void | Обновляет отображение формулы с использованием индексов через `FormulaUtils`. |
| checkFormula | Нет | void | Проверяет собранную формулу на соответствие цели (игра) или ищет ее в БД (лаборатория). |

## Жизненный цикл
- `onCreate`: Инициализирует данные, интерфейс и загружает элементы.

## Пользовательский интерфейс
- `activity_game.xml`: Содержит палитру элементов, кнопки действий (Индекс+, Индекс-, Backspace, Очистить, Проверить) и области отображения задачи и формулы.

## Взаимодействие между компонентами
- Использует `HelperDB` для данных.
- Использует `ElementAdapter` для отображения элементов.
- Использует `FormulaUtils` для форматирования и нормализации.

## Общая логика
Пользователи нажимают на элементы из списка, чтобы добавить их в формулу. Они могут настраивать индексы (например, H₂ вместо H) и использовать скобки. Кнопка «Проверить» определяет, совпадает ли формула с целью или существует ли она в базе данных.

## Упрощенное объяснение
Здесь происходит волшебство! Вы можете выбирать атомы из списка, чтобы строить молекулы. В режиме «Игра» приложение дает вам название, и вы пытаетесь его собрать. В режиме «Лаборатория» вы можете смешивать что угодно и смотреть, получится ли реальное вещество!
