# HelperDB

## Общая информация
Класс-помощник базы данных, управляющий базой данных SQLite (`chemistry.db`). Он отвечает за создание таблиц и заполнение начальных данных из JSON-файлов.

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| DATABASE_NAME | String | Имя файла на диске. |
| DATABASE_VERSION | int | Используется для управления обновлениями БД. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| onCreate | SQLiteDatabase db | void | Создает таблицы `elements`, `substances` и `progress`. |
| seedData | SQLiteDatabase db | void | Вызывает методы для загрузки начальных данных из JSON. |
| seedElements | SQLiteDatabase db | void | Разбирает `elements.json` из ресурсов и вставляет данные в таблицу. |
| seedSubstances | SQLiteDatabase db | void | Разбирает `substances.json` из ресурсов и вставляет данные в таблицу. |
| loadJSONFromAsset| String fileName | String | Читает файл из папки `assets` как строку. |

## Жизненный цикл
- Управляется системой Android. `onCreate` вызывается при первом доступе к БД.

## Пользовательский интерфейс
- Н/Д (Только управление данными).

## Взаимодействие между компонентами
- Используется в `GameActivity`, `SubstanceListActivity` и `DrawingActivity` для получения химических данных.

## Общая логика
Он гарантирует, что в приложении готова вся химическая информация (элементы, названия, формулы). При повышении версии базы данных он может пересоздать таблицы для обновления данных.

## Упрощенное объяснение
Этот класс работает как библиотекарь. Он расставляет полки (таблицы) и заполняет их книгами (химическими данными), чтобы остальная часть приложения могла найти то, что ей нужно.
