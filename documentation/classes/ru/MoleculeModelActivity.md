# MoleculeModelActivity

## Общая информация
Отображает интерактивную 3D-модель молекулы с помощью WebView и сервиса MolView.

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| wvMolecule3D | WebView | Контейнер для 3D-просмотрщика. |
| MODEL_IDS | Map<String, String> | База данных PubChem ID для распространенных веществ. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| setupWebView | Нет | void | Настраивает JavaScript и скрывает внешние меню с помощью внедрения CSS. |
| loadMolViewModel | Нет | void | Находит ID для формулы и загружает URL MolView. |

## Жизненный цикл
- `onCreate`: Начинает загрузку 3D-модели на основе переданной формулы.

## Пользовательский интерфейс
- `activity_molecule_model.xml`: Полноэкранный 3D-вид с оверлеем загрузки.

## Взаимодействие между компонентами
- Получает данные от `SubstanceAdapter`.

## Общая логика
Он ищет PubChem ID вещества в заранее определенной карте. Если ID найден, он загружает веб-страницу, которая визуализирует 3D-молекулу. Он использует JavaScript для «очистки» веб-сайта, чтобы он выглядел как часть приложения.

## Упрощенное объяснение
Этот экран позволяет вам увидеть, как выглядят молекулы в 3D! Вы можете вращать и приближать их. Это как виртуальный вид на молекулу.
