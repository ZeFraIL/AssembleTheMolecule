# Substance

## Общая информация
Класс-модель, представляющий химическое вещество (молекулу или соединение).

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| id | int | ID в базе данных. |
| formula | String | Химическая формула (например, "H2O"). |
| name | String | Обычное название (например, "Вода"). |
| className | String | Химический класс (например, "Оксид"). |
| difficulty | int | Уровень сложности для игрового процесса. |

## Детали методов
- Методы Геттеры и Сеттеры для всех переменных.

## Жизненный цикл
- Н/Д (Стандартный Java-объект).

## Пользовательский интерфейс
- Н/Д (Модель данных).

## Взаимодействие между компонентами
- Широко используется в `GameActivity`, `SubstanceListActivity` и `DrawingActivity`.

## Общая логика
Содержит все сведения о конкретном химическом веществе.

## Упрощенное объяснение
Папка, в которой собрано все, что мы знаем о конкретном веществе: его название, формула и к какой группе оно относится.
