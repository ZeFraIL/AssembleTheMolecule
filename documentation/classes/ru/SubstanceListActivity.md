# SubstanceListActivity

## Общая информация
Экран, отображающий список всех химических веществ, имеющихся в базе данных приложения. Он служит «химическим словарем».

## Таблица переменных
| Имя | Тип | Описание |
|---|---|---|
| rvSubstances | RecyclerView | Прокручиваемый список для отображения веществ. |
| helperDB | HelperDB | Доступ к базе данных. |

## Детали методов
| Имя | Параметры | Возврат | Логика |
|---|---|---|---|
| loadSubstances | Нет | void | Запрашивает базу данных обо всех веществах и настраивает адаптер. |

## Жизненный цикл
- `onCreate`: Загружает список немедленно.

## Пользовательский интерфейс
- `activity_substance_list.xml`: Простой вид списка.

## Взаимодействие между компонентами
- Использует `SubstanceAdapter`.
- Открывает `MoleculeModelActivity` через адаптер.

## Общая логика
Извлекает все строки из таблицы `substances` и представляет их в виде списка. Каждый элемент позволяет пользователю просмотреть его 3D-модель.
